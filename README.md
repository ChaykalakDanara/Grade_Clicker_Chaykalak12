# Grade Clicker — Кликер оценок

**Grade Clicker** — интерактивный кликер для набора баллов по курсу "Разработка мобильных приложений".

## Цель работы

Изучить жизненный цикл Activity в Android и научиться правильно
обрабатывать переходы между состояниями. В результате лабораторной работы будет
создано интерактивное приложение "Grade Clicker" (Кликер оценок), которое
демонстрирует работу lifecycle callbacks и сохранение состояния при изменении
конфигурации устройства

## Контрольные вопросы (ответы по ходу работы)

### 1. Какие три метода вызываются при запуске приложения?

При первом запуске вызываются:  
- `onCreate()`
- `onStart()` 
- `onResume()`

### 2. Чем отличается onPause() от onStop()?

- **onPause()** — Activity теряет фокус, но можетт быть ещё частично видна (например, поверх неё открылся диалог).
- **onStop()** — Activity становится полностью невидимой для пользователя (например, при нажатии Home или переключении в другое приложение).

### 3. Когда вызывается onRestart()?

`onRestart()` вызывается, когда Activity перезапускается после состояния `onStop()`, но до того, как она снова станет видимой.  
Например: нажал Home, потом вернулся в пртложение через Recents.

### 4. Что происходит при повороте экрана?

При повороте экрана Android уничтожает Activity (`onDestroy()`) и создаёт заново (`onCreate()`).  
Если не сохранить состояние, все данные (баллы, клики) теряются.

### 5. В чём разница между remember и rememberSaveable?

- `remember` — сохраняет данные только при рекомпозиции (перерисовке UI). При повороте экрана данные теряются.
- `rememberSaveable` — сохраняет данные и при рекомпозиции, и при configuration changes (поворот, смена языка, темы и т.д.).  
  В своей работе я использовала `rememberSaveable`, чтобы баллы не сбрасывались.

### 6. Почему onCreate() должен вызывать super.onCreate()?

`super.onCreate()` вызывает реализацию метода в ролительском классе (`Activity` / `ComponentActivity`).  
Это обязательное условие: там инициализируется внутреннее состояние Activity, без которого приложение не сможет работать корректно.

### 7. Для чего используется класс Log?

Класс `Log` позволяет выводить отладочные сообщения в консоль **Logcat**.  
Я использовала `Log.d()` с тегом `"MainActivity"`, чтобы отслеживать, когда вызываются методы жизненного цикла.

### 8. Какой метод вызывается только один раз за время жизни Activity?

Метод **`onCreat()`** — вызывается один раз при создании Activity.  
Если Activity уничтожится и создастся заново (например, при повороте), `onCreate()` вызовется снова.
